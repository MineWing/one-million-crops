01 / INSTALL

Running in three steps.

The plugin ships with SQLite and creates its configuration on first start.

  1. 1

    Meet the requirements

    Run Paper 1.21.11 on Java 21 or newer. Add PlaceholderAPI 2.12.3+ if you want placeholders.

  2. 2

    Drop in the JAR

    Copy OneMillionCrops-1.0.7.jar into your server's plugins/ folder.

  3. 3

    Restart and harvest

    Restart the server, then use /progress to open the crop progress menu.

PlaceholderAPI included. The expansion registers internally—there is no eCloud download command.
